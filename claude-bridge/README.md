# claude-bridge

OpenAI-compatible bridge for LiteLLM's `claude-sub` model: `server.mjs` over the
Claude Agent SDK, logged in with a Claude subscription. Built into the image
`agents-sandbox/claude-bridge`; runs as `as-claude-bridge`.

- `home/`, `workspace/`, `claude-bridge.env`: runtime and secrets (git-ignored)
- setup, modes, configuration, review notes: [docs/CLAUDE_BRIDGE.md](../docs/CLAUDE_BRIDGE.md)
